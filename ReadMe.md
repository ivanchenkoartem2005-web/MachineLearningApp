# Handwritten Digit Recognition & Clustering

## About
A machine learning project using Python and Scikit-learn to explore handwritten digit recognition and clustering.

The project uses the built-in Digits dataset, containing 1,797 handwritten digit images (0–9), each represented by 64 features.

## Algorithms
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- K-Means Clustering
- Hierarchical Clustering
- Principal Component Analysis (PCA)

## Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## How to Run
1. Clone this repository.
2. Install the required libraries:
   `pip install numpy pandas matplotlib seaborn scikit-learn`
3. Run:
   `python main.py`
